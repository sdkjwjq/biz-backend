# 平台通知操作说明

## 管理员发布

1. 打开“管理中心→通知管理”，点击“发送通知”。
2. 填写标题、正文，选择普通或重要通知。需要限时展示时填写截止时间。
3. 选择所有正常账号、指定部门或指定人员；可上传附件。
4. 点击“预览并发布”，核对内容和接收人数，再点“确认发布”。暂不发布可保存草稿。

接收人员按发布时间保存。以后新增账号不会自动补发，需另外发布。已发布正文不能覆盖修改，使用“更正发布”生成新版本并重新确认；原版本及回执保留。

## 用户阅读

普通通知在“消息中心”打开。重要通知在下次登录后优先展示，向下阅读完整正文后点击“确认已阅”；多条通知需逐条确认，随后进入平台。需要换账号可点击“退出登录”。首次强制改密先完成改密。

新通知不会打断已经登录用户正在编辑的内容。“全部已读”不替代通知的明确确认。阅读过程不要求停留固定秒数。

## 查看记录与撤回

通知列表点击“浏览记录”，查看发布时接收人、首次和最近打开时间、次数、确认时间及版本。可按人员、确认状态查询或导出全部接收记录。“查看”展示最近200条浏览事件。

“打开”与“确认已阅”分别记录；打开不等于用户已理解内容。误发或停止生效时点击“撤回”并填写原因，接收入口关闭，原浏览证据保留。到期通知不再阻止登录。
