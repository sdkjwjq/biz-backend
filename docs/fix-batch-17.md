## 隔离测试

- **负责人配置**：同一批含有效负责人、空负责人、已删除账号，正常负责人仍收到月度和年度通知，异常账号不产生通知。
- **兼管部门**：A、B 两部门分别生成带部门名、正确任务数的月度/年度通知；已删除部门和没有任务的部门不发送通知。
- **趋势空值**：空实际值按零、空删除标记按未删除处理；验证三级任务总数、已完成数和平均完成率；当天第二次调用返回跳过且没有重复插入。
- **趋势失败**：无任务时明确跳过；在隔离库设置 INSERT 失败触发器，接口返回错误且没有记录，移除触发器后重试成功。触发器只存在于随机测试库，finally 中删除。
- **原审计闭环**：`batch-17-audit.py --fixed` 三项正确行为断言通过。原始证据保留，未覆盖审计前结果。

测试人员、部门、任务、通知与趋势均为合成数据。测试准备初次使用不存在的负责人 ID，被现有外键正确阻止；随后保留外键并改用空值及软删除账号，未绕过数据库约束。
