# 任务筛选栏整理

## 改动

- 年度、任务范围、任务状态、待审阶段、处理部门、搜索、查询、重置统一排列，控件高 32px。
- 原快捷按钮组合并为任务范围下拉框，保留全部、我负责的、待我审核、已退回。
- 按筛选栏实际可用宽度适配：宽屏单行展示；较窄时收起两项审核条件至“更多筛选”，显示已选数量；更窄时搜索区域换行，避免溢出。
- 原组合筛选、即时下拉筛选、回车搜索、会话记忆、重置及权限口径保留。
- 验证时复现原有空结果刷新异常：空滚动锚点拼成非法 CSS 选择器。已增加非空判断，继续使用原滚动位置回退。
