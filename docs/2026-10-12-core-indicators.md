# 第三批：核心指标与工作纪实口径

## 使用入口

- 工作中心 → 核心指标；具有预算查看权限的账号也可从预算页顶部进入。
- 选择年度、月份，在对应指标点击“填报”，已有本人草稿时继续编辑。保存草稿不产生审核待办；提交时冻结名称、目标、填报人和审核人。
- 专业群是所选年度实际三级任务或四级目标责任人。核心指标同时向正常管理员和有效双高建设办公室（部门编号100）账号开放2025—2029年度填报，仍不可填未来月份。单独的学校领导查阅身份不授予填报资格。
- 归口审核使用对应原绩效的 `principalId`；通过后进入双高办归档。审核中心、消息、侧栏待办及连续审核均支持核心指标。
- 只有本次提交人可撤回尚无审核动作的记录。退回、撤回后重新填报带入本人原内容，原正式记录和审核日志保留。
- 总表每项指标一行，显示目标、归档值、最近正式填报及操作；展开行可看所选年度最近两次正式填报，历史记录可查全部。最近归档完成值在新提交待审期间保持不变；从未归档时显示空值。

## 数据及权限

十条指标按已确认编号精确映射原绩效；缺失、重复时提示修正配置，不按名称猜测。核心指标两项完成值独立保存，不修改原绩效。

同指标同年月最多一条在途审核；按映射、填报记录顺序加锁，并核对版本。归口审核不能由管理员跳过；双高办归档沿用现有管理员规则。草稿只允许创建者查看、编辑。每次正式提交和审核均保留记录。

工作纪实资格、年度任务范围、概览应填人数改为实际三级／四级责任关系；多个四级目标归并到同一三级任务，仅计一次。旧已提交内容及冻结快照不改写。管理员仍有原查阅、导出、逻辑删除能力，不因此新增全校填报能力。
