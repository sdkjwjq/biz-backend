# 登录页凭原密码重置密码

前端提交：`378c94a`。后端代码、测试和本文档由同一功能提交交付。

## 行为与接口

登录按钮下新增“重置密码”，带入账号，验证原密码及两次新密码。新密码至少 8 位且包含大写、小写字母及数字。失败保留输入；成功清空密码并返回登录，不自动登录。提交中禁用重复操作，关闭后清除密码和校验信息。

新增 `POST /api/system/password/reset`，JSON 字段：`user_id`（数字账号或数字字符串）、`old_password`、`new_password`。成功 HTTP 200，返回 `{ "message": "密码重置成功，请使用新密码登录" }`；参数错误 HTTP 400；账号不存在、已删除或原密码错误统一 HTTP 401，错误体沿用 `ErrorVO`。该接口免 Token，但现有改密接口继续要求 Token。

SQL 以账号、原密码及未删除条件原子更新，仅修改密码与更新时间；密码采用二进制比较，保留大小写和尾部空格区别。登录、改密和本次重置请求对象的字符串表示不输出密码，避免调试日志泄漏。前端仅对此接口关闭全局 401 跳转处理。

不调整账号状态规则、存储方式、既有会话有效期；不提供忘记原密码找回功能，无数据库迁移。

## 验证

- `scripts/run-review-regression.py`：38 项真实 HTTP/MySQL 隔离回归，包含新加的两项测试，覆盖管理员及普通用户重置、旧密码失效、新密码登录、字段不变、参数校验、删除账号、大小写/尾空格错误、并发更新只有一方成功，以及现有强制改密回归。
- `scripts/ui-audit/login-password-reset.cjs`：10 项 Playwright 检查，真实接口验证重置及重新登录，另检查带入账号、空值、弱密码、确认不一致、错误原密码、关闭清空、重复提交、无强制改密提示及窄屏布局。无浏览器 pageerror。
- 前端修改文件 ESLint、生产构建，后端打包及提交差异检查。
- 测试只用随机隔离数据库及合成账号；截图和结果见 `docs/evidence/login-password-reset-2026-09-18/`。复跑需先设置测试数据库密码环境变量并以 `serve.py --fixture base --frontend-port 15273` 启动全新隔离环境，完成后写入 `target/ui-audit/STOP` 清理。
