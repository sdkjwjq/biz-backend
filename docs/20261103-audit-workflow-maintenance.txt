审核流程修复（2026-11-03）

普通页面统一使用真实提交时间之后的审核记录。任务、专家详情、绩效关联任务、工作纪实证据和详细导出采用相同规则；原始审核日志不删除、不改写。
步骤文字按当前审批状态显示。已完成步骤有记录时显示实际操作人及时间；无记录时不推测审核人或日期。当前待审显示当前处理人，不显示下一阶段已完成。

经最新备份确认的25条任务待办仅修正处理人，不改变审批状态、填报值或提交时间；2条已删除成果的待审残留退出活动待办。
维护工具为本地命令行入口，不提供HTTP接口，不写入审核日志、管理操作日志或前台异常列表。备份和核对文件仅供服务器维护、回退使用。

java -jar backend/biz_backend-1.0-SNAPSHOT.jar --audit-workflow-maintenance check /绝对路径/check.json
java -jar backend/biz_backend-1.0-SNAPSHOT.jar --audit-workflow-maintenance apply /绝对路径/applied.json
java -jar backend/biz_backend-1.0-SNAPSHOT.jar --audit-workflow-maintenance rollback /绝对路径/applied.json

数据库配置从SPRING_DATASOURCE_URL、SPRING_DATASOURCE_USERNAME、SPRING_DATASOURCE_PASSWORD读取，不在命令参数中传密码。维护模式不启动Web端口或定时任务。
正式更新由update.sh统一运行，先检查，再停止服务并备份，再修正。所有候选先校验，出现活动记录身份或配置冲突时整批停止；已处理、撤回或删除的提交跳过。
部署成功后保存服务器私有一次性标记；后续更新保留管理员的新配置，不重复应用旧清单。

回滚只允许提交、配置、审核日志、相关通知仍与维护后快照一致时执行；后续审批或通知阅读发生变化则拒绝回滚。禁止用旧全库覆盖更新后的业务。
不执行2025年历史审核流程重建脚本，不重算任务或绩效，不补造历史审核证据，不修改已提交纪实快照。
