# 统一身份认证接入（本地开发阶段）

目前只接入学校统一身份认证的 OAuth2.0 登录。统一消息平台的“待办”是另一套接口，尚未接入。

## 已完成

- 登录页可在启用配置后显示“学校统一身份认证登录”。平台账号密码登录保留。
- 服务端生成并校验 `state`，用一次性授权码在服务端换取身份；浏览器不接触应用密钥。
- 仅用学校返回的数字工号匹配现有平台账号，不按姓名猜测，也不自动创建账号。停用或删除的账号不能登录。
- 统一认证成功后，平台按现有角色、数据范围和审核职责发放一小时会话。统一认证登录不触发平台本地密码的首次修改提示；原密码登录规则不变。
- 平台主动退出时先结束平台会话，再访问学校统一注销地址。学校应用登记中的业务系统退出地址可设为 `http://172.19.2.81/sso/logout`。

## 学校内网配置

通过服务器的私有环境变量提供以下值，不要把应用密钥写进源码、Git、前端配置或更新包：

```text
SSO_ENABLED=true
SSO_CLIENT_ID=<学校提供的 app_key>
SSO_CLIENT_SECRET=<学校提供的 app_secret>
SSO_CAS_BASE_URL=http://ca.xzcit.cn/cas
SSO_REDIRECT_URI=http://172.19.2.81/
```

`SSO_REDIRECT_URI` 必须与学校登记的“接入地址”完全一致，包括协议、端口和末尾斜杠。线上启用前须确认应用登记信息，并通过真实账号完成授权、回调、退出和停用账号验证。当前人在校外，内网回调地址不可达，未进行学校系统的真实联调。

## 本地验证

使用模拟 OAuth 服务验证了状态校验、授权码交换、工号映射、身份冲突拒绝、停用账号拒绝和本地强制改密标记保留。另用 2026-11-05 备份建立临时隔离库，在 Edge 中走通登录页按钮、授权码回调、角色选择、任务页、平台退出及模拟学校注销。角色选择页“返回登录”也已改为同步访问学校注销；测试后删除隔离库。结果摘要见 `docs/本地模拟浏览器测试结果.json`。该测试未连接学校认证服务。运行：

```text
mvn -Dtest=SchoolSsoServiceTest test
```

前端在 `frontend/` 下运行 `npm ci`、`npm run build` 和 `npx eslint src/api/user.js src/router/index.js src/views/Login.vue src/views/Home.vue src/views/ReviewRoleChoice.vue src/views/SsoLogout.vue`。
