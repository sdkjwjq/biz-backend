先按 `scripts/ui-audit/README.md` 设置数据库密码环境变量并启动全新 `--fixture review` 隔离环境，再执行：

```powershell
python scripts/ui-audit/seed-batch-8.py
node scripts/ui-audit/batch-8-audit.cjs budget-race
node scripts/ui-audit/batch-8-audit.cjs empty-trend
node scripts/ui-audit/batch-8-audit.cjs year-race
New-Item -ItemType File -Path target/ui-audit/STOP -Force
```

种子脚本仅允许 state.json 中名称匹配 `biz_review_test_<32位十六进制>` 的库；每个全新环境只加载一次，禁止用于业务库。结束后等待服务脚本确认清理。
