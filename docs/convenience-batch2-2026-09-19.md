# 便利操作第二批交付（2026-09-19）

## 本批功能

- 任务、绩效、成果增加单选快捷筛选，与已有年度、搜索及其他筛选取交集；提供重置筛选。
- 任务按负责人、当前待办、当前退回筛选；绩效按负责人及年度筛选，自动汇总指标不进入独立审批退回筛选；成果按创建人、待办、当前退回状态筛选。
- 会话内保存三个页面的年度、已执行搜索、快捷筛选、其他筛选、展开目录及滚动锚点。重新读取权限范围内的数据后恢复，退出清除、不同账号隔离。三个业务列表均为树形全量列表，没有分页。
- 绩效、成果详情增加上一个、下一个及位置计数，沿当前筛选结果遍历，跳过目录。加载、提交、审批期间禁用；切换前保护未提交内容，切换后重置表单和滚动位置。
- 显式详情链接优先于历史筛选。缓存不可用仍可正常浏览；已失效目录及滚动锚点自动修正。

第三批“提交并审核下一条”尚未实施，按约定等待本批审核。

## 后端兼容处理

新增需要 JWT 的 GET `/biz/tasks/quick-filters` 和 `/performance/quick-filters`，仅返回现有列表权限内的 ID、年度摘要，不修改业务写接口、数据库结构和状态流转。

现有任务退回会同时设置 `is_delete=1`，因此不能仅查询未删除审核单。按最新提交判断退回；更新的重提或撤回记录阻止历史退回重新出现。现有多项四级填报共用三级任务审核单，同时兼容挂在四级任务上的历史记录。绩效按指标与年份选择最新提交，排除撤回，排除 `1.1.*`、`1.2.*` 自动汇总指标。
