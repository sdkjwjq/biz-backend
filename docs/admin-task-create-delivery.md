# 管理员管理功能：第一批交付

## 范围

仅交付管理员新增三级建设任务。任务移交、绩效移交、关联编辑及对应管理日志和迁移属于后续两批，按约定等待本批审核。

入口：管理员登录 → 工作中心 → 任务 → 新增任务。

- 数据库当前角色为管理员才显示入口，选项读取和保存再次核验权限。
- 选择既有二级目录，年度为 2025—2029；目录跨年度复用，归口部门、责任人及两类审核人独立选择。
- 表单涵盖编号、名称、目标、数据类型及原有描述、预期成果、材料要求；保存前逐项预览和说明影响。
- 创建固定为未开始、完成值和进度均为零，权重沿用默认 1，不自动关联绩效。
- 创建后打开详情。“返回列表并定位”在筛选排除目标时提示清除筛选；可以取消，保留原筛选。
- 保存期间禁止重复提交；失败保留输入并滚动到错误提示。关闭或路由离开时确认未保存内容。窄屏表单为单列，正文独立滚动。

## 接口和兼容

- 新增 `GET /biz/tasks/manage/capabilities`、`GET /biz/tasks/manage/options`。选项只返回必要的账号标识和姓名，不返回密码。
- 复用 `POST /biz/tasks/manage/add`，默认保留原成功文本；新页面传 `returnDetail=true` 获取新任务 ID。
- 参数校验返回 HTTP 400，非管理员返回 403，重复编号返回 409，错误体仍为 ErrorVO。
- 项目行锁和编号校验在同一事务内执行，并发创建相同项目、年度、编号只能成功一次；编号按数据库既有排序规则比较、忽略首尾空格。
- 拒绝伪造任务 ID、已完成值、进度和审核状态；祖先路径由后端生成。局部拒绝年度、层级和人员编号的小数截断。
- 有效账号沿用现有未删除规则，不重新解释历史账号 status 字段，也不改登录规则。
- 本批不修改数据库结构，无需迁移或回滚 SQL。

## 部署与回滚

本批先部署后端，再部署前端。构建产物为后端 `target/biz_backend-1.0-SNAPSHOT.jar`、前端 `dist/`。部署前备份原应用和数据库；本次交付未替换现有手测后端。

回滚对应前后端功能提交，或恢复上版构建产物。已创建任务使用既有表结构，可保留，不删除业务记录。后续移交批次再提供新增表和字段的正向、回滚 SQL。
