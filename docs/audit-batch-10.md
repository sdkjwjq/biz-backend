## 10-1【高 / BUG】任务详情显示 B，却审批 A

- 位置：`biz/src/components/Works.vue:2538`、`:2821`、`:3240`。
- 原因：打开任务详情后，审核数据请求没有任务归属或请求序号校验；关闭抽屉也没有使旧请求失效。旧响应可覆盖新任务的 `auditList`，审批直接使用 `latestAudit.subId`，未核对其任务 ID。
- 影响：用户查看 B 并点击确认，实际推进 A 的审批流程。后端收到的 A 单号属于该审核人的合法待办，因此权限检查不能阻止该错审。
- 建议：按任务 ID 和请求序号隔离详情、子任务、审核单和日志加载；关闭或卸载使旧请求失效并清空旧数据；加载期间禁止审批，提交前校验审核单归属并固定提交上下文。
