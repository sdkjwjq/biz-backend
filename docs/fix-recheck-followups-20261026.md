## NEW-01：预算草稿处理早于注销

原流程先注销并清除 Token，最后跳转才触发预算离开检查，因此“保存后继续”必然失败。

现流程为：退出确认 → 页面现有离开检查 → 保存成功或明确放弃 → 目标路由解析完成 → 启动注销请求并清理当前会话 → 登录页。注销请求在清理前捕获当前 Token，响应等待不会再次清理新登录会话。

- 用户取消退出、取消草稿离开，均保留原会话和输入。
- 保存失败时不调用注销，保留会话和草稿，可继续重试。
- 同一轮只导航一次，复用现有页面守卫，避免第二次草稿询问。
- 退出按钮防止重复触发；中断或失败的导航清理临时退出状态。
- 登录路由仅识别当前路由器私有的退出意图，不通过 URL 参数或 Token 角色绕过检查；普通已登录用户访问登录页仍按原规则返回工作页。
- 注销接口关闭自身的通用401跳转，由退出流程负责页面跳转。接口失败仍沿用原本地退出行为，其他接口的会话失效处理不变。

涉及前端 `Home.vue`、`router/index.js`、`api/user.js` 及新增 `utils/logoutNavigation.js`。没有修改各业务填报或审核规则。

## NEW-02：数据维护页提供外层滚动

数据维护根容器改为占满可用高度、允许纵向滚动；内嵌预算根容器按内容确定高度，避免百分比高度与外层固定视口冲突。

- 仅调整 `AdminData.vue` 局部样式，保留全站内容容器设置。
- 预算宽表继续使用原有内部横向、纵向滚动。
- 筛选、保存等按钮及完整表格可通过正常鼠标滚动访问。
