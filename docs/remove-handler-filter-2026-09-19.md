# 移除绩效与成果的当前处理部门筛选

按用户最新要求，绩效页保留归口部门、成果页保留报送部门，移除两页的当前处理部门控件、过滤逻辑及会话记忆字段。任务页不变。

旧缓存里的 handler 条件不再恢复；保存页面状态时不再写入该字段，避免隐藏条件导致记录消失。原范围、年度、类型、搜索、重置和详情定位继续可用。

验证：5 组 Playwright 检查通过，含向旧缓存注入不存在的处理部门后刷新，确认记录正常显示；两页各 5 种屏宽无溢出、浏览器异常 0。修改文件 ESLint 和前端构建通过。证据见 `docs/evidence/remove-handler-filter/`。

仅更新前端，无需更新后端或数据库。回滚本次前端提交后重新构建即可。保留原有未提交修改。
